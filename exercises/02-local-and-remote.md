# Exercise 2 — Local and Remote

## Goal

See the difference between changing a local file and changing the shared repository on GitHub.

## Steps

1. Clone your training repository with GitHub Desktop.
2. Locate the repository folder on your computer.
3. Open `README.md` in a text editor.
4. Add a temporary line such as:

   > Local test change

5. Save the file.
6. Open GitHub Desktop and look at **Changes**.
7. Open the repository on github.com.

## What should you notice?

The change appears in GitHub Desktop because the local file changed.

The change does **not** appear on github.com because you have not committed and pushed it.

Remove the temporary line before continuing.

Explain in your own words:

- local repository;
