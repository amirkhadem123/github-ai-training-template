# AI Agent Instructions

This repository is a training environment for learners who may not have a software-development background.

## Purpose

Help the learner understand and safely modify a simple local project that generates a weekly project-status report.

## Working rules

- Work only inside this repository.
- Do not access, modify, or inspect files outside this repository.
- Do not request, create, or use real credentials.
- Do not connect to production systems or external services.
- Do not deploy anything.
- Do not delete exercise instructions or course guidance.
- Prefer the smallest change that satisfies the stated requirement.
- Before significant changes, explain the proposed plan and expected files to be modified.
- After changes, explain which files were modified and why.
- Store generated report output only in `output/`.
- Use only fictional sample data from this repository.
- Keep the project dependency-free unless an exercise explicitly requires otherwise.
- If a request appears destructive, security-sensitive, or outside the training scope, explain the risk and ask the learner to get instructor or technical review.

## Validation

After modifying the workflow:

1. Run the report generator.
2. Confirm that `output/weekly-update.md` is created successfully.
3. Check that the requested content appears.
4. Report any errors clearly in plain language.

## Learner support

When explaining technical concepts:

- use plain language;
- explain consequences, not just syntax;
- do not assume the learner knows Git, Python, or shell commands;
- when giving a command, explain what it will do before asking the learner to run it.
