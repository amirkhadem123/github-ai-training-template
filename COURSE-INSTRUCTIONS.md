# Course Instructions

This repository supports the hands-on exercises in the course.

## Ground rules

- Work only in **your own repository created from the template**.
- Do not work directly in the original template repository.
- Create a new branch before each substantial exercise.
- Ask your AI assistant to inspect and explain before making changes.
- Prefer small, reviewable changes.
- Review changed files before committing.
- Do not add real credentials, customer data, or production configuration.

## Recommended working pattern

### 1. Orient

Ask:

> Review this repository and explain what it does in plain English. Identify the important files and folders. Do not make changes.

### 2. Plan

Ask:

> Review the requirement and propose the smallest reasonable implementation. Tell me which files you expect to change and how you will validate the result. Do not implement anything yet.

### 3. Implement

When the plan looks reasonable:

> Implement the agreed plan. Keep the change limited to the requirement.

### 4. Validate

Ask:

> Run the workflow against the sample data and verify that the output satisfies the requirement.

Then inspect the output yourself.

### 5. Review

Ask:

> Summarize exactly what changed. List the files you modified and explain why each change was necessary. Flag anything that should receive technical review.

Then inspect the Changes view in GitHub Desktop.
