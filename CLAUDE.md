# Claude Code Project Instructions

Follow the project-wide rules in `AGENTS.md`.

Additional guidance for this training repository:

- Treat the learner as new to software development.
- Explain plans and commands in plain language.
- Do not make broad refactors unless the learner explicitly requests them.
- Keep edits small and easy to review.
- Before changing files, identify the expected scope.
- After changing files, summarize the diff and validation result.
- Never request real credentials or connect to external systems.
